# Ejercicio 3 - totalIntegers

Escribe una función que reciba un array u objeto con un nivel de anidamiento arbitrario y devuelva el número total de enteros almacenados dentro de ese array u objeto.

```javascript
totalIntegers([[[5], 3], 0, 2, ['foo'], [], [4, [5, 6]]]); // devuelve 7
totalIntegers({ a: 1, b: { a: [5, 10], b: 11 } }); // devuelve 4
```
