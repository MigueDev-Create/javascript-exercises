# Ejercicio 1 - Factorial

Escribe una función [factorial](https://simple.wikipedia.org/wiki/Factorial) recursiva que reciba un entero no negativo y devuelva el producto de todos los enteros positivos menores o iguales al número de entrada. Una entrada de `0` debe devolver `1`. La función solo debe aceptar números, así que `'4'` no debe aceptarse por ser una cadena. Todas las entradas inválidas deben devolver `undefined`.

Por ejemplo:

```javascript
factorial(5); // 5 * 4 * 3 * 2 * 1, Salida: 120
factorial(0); // Salida: 1
factorial(7.2); // Salida: undefined
factorial('4'); // Salida: undefined
```
