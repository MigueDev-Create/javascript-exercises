# Ejercicio 15 - ¡Consigue los títulos!

Se te da un array de objetos que representan libros con un autor y un título, con este aspecto:

```javascript
const books = [
  {
    title: 'Book',
    author: 'Name'
  },
  {
    title: 'Book2',
    author: 'Name2'
  }
]
```

Tu tarea es escribir una función que reciba el array y devuelva un array de títulos:

```javascript
getTheTitles(books) // ['Book', 'Book2']
```

## Pistas

- ¡Deberías usar un método incorporado de javascript que haga la mayor parte del trabajo por ti!
