# Ejercicio 07 - Invertir una cadena

Bastante sencillo: escribe una función llamada `reverseString` que devuelva su entrada, ¡invertida!

```javascript
reverseString('hello there') // devuelve 'ereht olleh'
```

## Pistas

Las cadenas en JavaScript son inmutables y, por tanto, no se pueden invertir directamente en el mismo sitio. Aunque no existe un método incorporado para esto, se pueden usar varios enfoques alternativos, apoyándose en los conceptos que has visto en las lecciones.
