# Ejercicio 14 - Fibonacci

Crea una función que devuelva un miembro concreto de la sucesión de Fibonacci (serie de números en la que cada número es la suma de los dos anteriores). Para saber más sobre las sucesiones de Fibonacci, visita: https://en.wikipedia.org/wiki/Fibonacci_sequence

En este ejercicio, la sucesión de Fibonacci utilizada es 1, 1, 2, 3, 5, 8, etc. (es decir, empezando en 1, no en 0).

```javascript
fibonacci(4); // devuelve el 4º miembro de la serie: 3  (1, 1, 2, 3)
fibonacci(6); // devuelve 8
```

Si recibe un número negativo, la función debe devolver `"OOPS"`.
