# Ejercicio 12 - Calculadora

El objetivo de este ejercicio es crear una calculadora que haga lo siguiente:

1. `add()`: recibe dos números y devuelve su suma
2. `subtract()`: recibe dos números y devuelve el resultado de restar el segundo al primero
3. `sum()`: recibe un array de números y suma todos los números
4. `multiply()`: recibe un array de números y multiplica todos los números
5. `power()`: recibe dos números (base y exponente) y devuelve el resultado de elevar la base a ese exponente
6. `factorial()`: dado un único número, halla su [factorial](https://www.mathsisfun.com/numbers/factorial.html)

Por favor, completa cada función con tu solución. ¡Asegúrate de hacer `return` del valor para poder probarlo con Jest! Para ver el valor esperado, echa un vistazo al archivo `.spec.js` que contiene los casos de prueba de Jest.
