# Ejercicio 04 - mathEquations

Sustituye las cadenas que hay a la derecha del `=` por la expresión que describen. **No** escribas manualmente el resultado de la ecuación.

Actualmente las variables son cadenas. En su lugar deben ser ecuaciones matemáticas.

Para ayudarte, la primera variable ya está resuelta:

```js
const a = 1 - 1 // ¡Regalo! Esta es la respuesta a "uno menos uno"
```

El siguiente es un ejemplo de respuesta **incorrecta**:

```js
const a = 0 // ¡MAL! ¡Tienes que escribir la ecuación, NO poner directamente su resultado!
```
