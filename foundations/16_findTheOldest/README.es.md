# Ejercicio 16 - Encuentra a la persona más longeva

Dado un array de objetos que representan personas con un año de nacimiento y de fallecimiento, devuelve la persona más longeva.

Ahora que has llegado al último ejercicio, deberías sentirte bastante cómodo obteniendo la información que necesitas de los casos de prueba. Echa un vistazo a cómo está construido el array de objetos en los tests de este ejercicio para que te ayude a escribir tu función.

## Pistas

- Debes devolver el objeto completo de la persona, aunque los tests en su mayoría solo comprueban que el nombre sea correcto.
- Hay muchas formas de hacer esto usando métodos incorporados de array como `reduce`, ¡o incluso encadenando varios!
- Uno de los tests comprueba personas sin fecha de fallecimiento... usa la función Date de JavaScript para obtener su edad a día de hoy.
