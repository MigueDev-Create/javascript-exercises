# Ejercicio 06 - repeatString

Escribe una función que simplemente repita la cadena un número dado de veces:

```javascript
repeatString('hey', 3) // devuelve 'heyheyhey'
```

Esta función recibirá dos argumentos, `string` y `num`. Si `num` es un número negativo, devuelve la cadena `'ERROR'` en su lugar.

Usa bucles para implementar `repeatString` en lugar de usar el método incorporado `String.prototype.repeat`, que tiene el mismo comportamiento.

*Nota:* Los ejercicios posteriores a este no tendrán los argumentos ya proporcionados como ocurre aquí: a partir de ahora tendrás que definirlos tú. Así que lee con atención el README de cada ejercicio para ver qué tipo de argumentos se esperan.
