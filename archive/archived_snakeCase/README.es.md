# Ejercicio XX - snakeCase

Convierte frases y palabras a snake case

> Snake case (o snake\_case) es la práctica de escribir palabras compuestas o frases en las que los elementos se separan con un guion bajo (\_) y sin espacios, y donde la letra inicial de cada elemento suele ir en minúscula, como en "foo\_bar"

```javascript
snakeCase('Hello, World!') // hello_world
snakeCase('snakeCase') // snake_case
```
